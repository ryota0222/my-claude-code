# Project Guidelines

## Accuracy of Responses

- When stating version requirements or specifications for libraries, frameworks, or tools, verify against primary sources such as official documentation, release notes, or package.json before answering.
- Do not make definitive claims about information that has not been verified. When uncertain, explicitly state "this needs to be verified."
- When asked, use WebFetch, gh CLI, or other tools to retrieve the latest information and provide answers with supporting evidence.
